# Project

## Working here

- Install dependencies with the lockfile's package manager (npm, pnpm, yarn, or bun).
- Run the test and lint scripts from `package.json` before calling work done.
- Record significant design choices in `docs/decisions/`.

## Agents, commands, and skills

- `reviewer`: read-only review of the current change.
- `commit`: write a conventional commit for staged changes.
- `writing-tests`: conventions for adding or fixing tests.
